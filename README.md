# Divyansh Chandra - Portfolio Engine

Modern portfolio and technical showcase engineered with Next.js, React, TypeScript, and Supabase.

## Overview
- **Brand Identity**: Divyansh Chandra (`DC.`)
- **Focus Areas**: Generative AI & LLM Systems, Python Workflow Automation, Technical SEO & Digital Analytics
- **Live Site**: [https://www.divyanshchandra.online](https://www.divyanshchandra.online)

## Features
- Interactive 3D/Framer Motion UI components and Case Studies
- Journal system with interactive category folders
- Dynamic admin dashboard for managing articles, case studies, and projects
- Programmatic SEO metadata, multi-size favicon suite, and automated sitemap generation

## Tech Stack
- **Framework**: Next.js 16 (Turbopack) & React
- **Language**: TypeScript
- **Database / Backend**: Supabase
- **Styling**: Vanilla CSS with modern custom design system & Framer Motion
